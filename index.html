☁️ 雲端同步設定

把你的資料同步到自己的 GitHub 私人資料庫，不同電腦就能共用同一份

這是怎麼運作的？

你的資料會存到你自己的 GitHub 私人資料庫（kwanabc/finance-vault，只有你登入 GitHub 才看得到，網站訪客看不到）。

在另一台電腦打開同一個網址 → 點左下角這顆 ☁️ → 貼上同一組授權碼 → 資料就會出現。

資料會離開這台電腦、經加密連線送到 GitHub。若你要求「任何資料都不上傳」，請改用「💰 資金帳本與備份」裡的手動備份檔。

貼上一次就好，會存在這台電腦的瀏覽器裡（兩個網站共用同一組）。畫面上不會顯示完整內容。
