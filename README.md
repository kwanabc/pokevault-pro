# PokéVault Pro — Pokémon 卡牌買賣・送評・資金管理系統

一個單一檔案的網頁 App（只有 `index.html`），用瀏覽器就能打開，用來管理 Pokémon 卡牌的**買入成本、送評費用、賣出差價與資金池**。

## 五大功能區

| 分頁 | 用途 |
|---|---|
| 📊 總覽與資金池 | 總資產淨值、可用現金、壓貨成本、持倉預估市值、已實現淨利與 ROI；2 張圖表（資金配置圓餅圖、獲利來源柱狀圖）；卡牌流轉狀態管道（裸卡 → 送評中 → 鑑定磚 → 已售出） |
| 🃏 卡牌庫存與買賣 | 每張卡的買入價、運費、評費、加價、落地成本、市值、淨利與 ROI；可搜尋卡名/編號/Cert#、依狀態/語言/評級機構篩選；勾選裸卡一鍵建立送評批次 |
| 🏆 送評批次管理 | 建立 PSA／BGS／CGC／ARS 送評批次，輸入每張基本評費 + 整批運費/保險/代送費，系統**自動把整批雜費平均分攤到每張卡**；批次進度五階段（準備中→已寄出→鑑定中→已出分→已寄回）；登錄出分分數、Cert#、加價 (Upcharge) 與最新市值 |
| 🧮 送評與差價試算器 | 買卡前先算：送評期望值 (EV)、損益兩平價、最低 Gem 10 出分機率門檻，並與「裸卡直接轉賣」對比；內建 eBay／SNKRDUNK／Mercari／拍賣等平台手續費範本 |
| 💰 資金帳本與備份 | 設定起始本金、記錄注資／提領／雜項支出；全域現金流水帳自動整合（起始本金 + 買卡支出 + 送評費 + 賣卡回款 + 手動記錄）；匯出 CSV 報表 / JSON 備份、匯入還原、重置範例資料 |

## 兩個小特色

- **HKD ⇄ USD 一鍵切換**：右上角可即時調整匯率（預設 1 USD = 7.80 HKD），所有金額立即換算；輸入資料時也能自選用哪種幣別輸入（內部一律換算成 HKD 儲存）。
- **自動成本連動**：買卡、送評、賣出都會即時反映到可用現金、壓貨成本與淨利，不需要手動記帳。

## 最重要的一件事：你的數字不會上傳

所有卡牌與資金資料都只存在**你自己電腦的瀏覽器**裏（瀏覽器內建的 LocalStorage，key: `pokevault_pro_state_v1`）。這個網站沒有任何後端伺服器，所以：

- 別人打開這個網址，只會看到程式本身和內建的**範例資料**，看不到你的真實紀錄；
- 換電腦、換瀏覽器、或清除瀏覽器資料，數字就會消失 → 請定期用「📦 匯出完整系統備份 (.json)」備份；
- **千萬不要把備份的 .json 或 .csv 檔上傳到這裏或任何公開地方**，那些檔案裏面才是你的真實數字（本專案已用 `.gitignore` 擋掉 `*.json` 與 `*.csv`）。
- 這個 App **沒有密碼鎖**（跟另一個貸款系統不同），請不要在共用電腦上打開。

## 怎麼使用

1. 開網址，或在電腦上雙擊 `index.html`。
2. 到「💰 資金帳本與備份」設定你的起始本金。
3. 按右上角「+ 新增入庫卡牌」開始記錄買入的卡（卡名、系列卡號、語言、買價、運費、預估市值）。
4. 要送評時：在庫存頁勾選裸卡 →「📦 勾選裸卡建立送評單」→ 填評費與整批運費。
5. 出分後按「🏆 登錄出分結果 / 加價」，填入分數、Cert#、加價與最新市值，卡牌會自動轉為「在庫鑑定磚」。
6. 賣出時按「售出」記錄成交價、平台手續費與運費，系統自動算出這筆的淨利與 ROI。

## 技術說明

- 純前端單檔：HTML + Tailwind CSS（CDN）+ Chart.js（CDN），沒有建置步驟、沒有套件要安裝。
- 內部以 HKD 為基準幣別，顯示時才依匯率換算成 USD。
- 修改網站：直接用文字編輯器改 `index.html` 再上傳即可。
